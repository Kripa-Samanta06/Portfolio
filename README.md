# Kripa Samanta — 3D Software Developer Portfolio

A cutting-edge, high-performance 3D portfolio website engineered for **Kripa Samanta** (Computer Science Engineering Student & Aspiring Software Developer) specializing in Artificial Intelligence & Machine Learning (AIML), Full-Stack Systems, and Cloud Architecture.

---

## 🚀 Tech Stack

- **3D Engine**: [Three.js](https://threejs.org/) & [React Three Fiber](https://r3f.docs.pmnd.rs/) with [@react-three/drei](https://github.com/pmndrs/drei)
- **Frontend Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with Glassmorphism & Cyberpunk aesthetics
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & CSS keyframes
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio Synthesis**: Native Web Audio API procedural sound engine
- **Interactions**: Canvas Confetti & Direct 1-Click Compose

---

## ✨ Features

- 🌐 **Interactive 3D Cyber Core**: Real-time distorted icosahedron core, dodecahedron wireframe cage, 3 orbital rings, orbiting satellite nodes, and cursor parallax tracking.
- 🌌 **Particle Constellation**: Additive blending particle stars with cosmic orbital drift.
- 🎓 **Academic & Education**: Highlights Brainware University (B.Tech CSE AIML, Expected 2028), 9.05/10 GPA, and coursework.
- 💻 **Featured Projects Showcase**:
  - **eVidyaHub**: Collaborative Q&A platform (Python, Django, Role-based Dashboard).
  - **Fincy**: Modern personal expense manager (TypeScript, Dynamic UI).
- 🛠️ **Interactive Skills Matrix**: Filterable tech stack by Languages, Frameworks, Databases, Tools & Platforms, and Core CS.
- 📜 **Printable Curriculum Vitae Modal**: Instant formatted resume view with 1-click print/PDF export.
- 📬 **Direct Contact Dispatch**: 1-click Gmail Web compose, desktop mail app support, and real-time IST Kolkata status.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Kripa-Samanta06/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
